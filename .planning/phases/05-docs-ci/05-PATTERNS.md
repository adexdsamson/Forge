### `.github/workflows/ci.yml` (NEW — config, CI)

**Analog:** `.github/workflows/publish.yml` (the only existing workflow; provides the runner/node/npm-ci skeleton)

**Current analog structure** (`.github/workflows/publish.yml`, lines 1–34 — full file):
```yaml
name: Forge Environment Deployment

on:
  push:
    branches: [main]
  workflow_dispatch:

jobs:
  publish:
    runs-on: ubuntu-latest

    steps:
      - name: checkout
        uses: actions/checkout@v3

      - name: node
        uses: actions/setup-node@v3
        with:
          node-version: 20
          registry-url: https://registry.npmjs.org

      - name: install
        run: npm ci

      - name: publish
        run: npm publish --access public
        env:
          NODE_AUTH_TOKEN: ${{secrets.NPM_ACCESS_TOKEN}}
```

**What `ci.yml` copies from this analog:**
- `runs-on: ubuntu-latest` — same runner (D-07)
- `actions/setup-node` with `node-version: 20` — same Node version
- `npm ci` install step — same package install command

**What `ci.yml` changes vs the analog:**
- Trigger: `push: branches: ['**']` + `pull_request: branches: ['**']` (not push-to-main only)
- No `registry-url` (no publish step)
- No `NODE_AUTH_TOKEN` env
- Replace the publish step with `npm run lint` then `npm test`
- SHA-pin both actions (D-09): `actions/checkout@11bd71901bbe5b1630ceea73d27597364c9af683` and `actions/setup-node@49933ea5288caeca8642d1e84afbd3f7d6820020`
- Add `cache: 'npm'` to `setup-node` (available in v4; not present in current analog's v3)

**Target structure** (from RESEARCH.md Pattern 4):
```yaml
name: CI

on:
  push:
    branches: ['**']
  pull_request:
    branches: ['**']

jobs:
  ci:
    runs-on: ubuntu-latest

    steps:
      - name: Checkout
        uses: actions/checkout@11bd71901bbe5b1630ceea73d27597364c9af683 # v4.2.2

      - name: Setup Node
        uses: actions/setup-node@49933ea5288caeca8642d1e84afbd3f7d6820020 # v4.4.0
        with:
          node-version: 20
          cache: 'npm'

      - name: Install
        run: npm ci

      - name: Lint
        run: npm run lint

      - name: Test
        run: npm test
```

| # | Location | Change |
|---|---|---|
| 1 | `on:` trigger | Replace `push: branches: [main]` with `release: types: [published]` (D-08) |
| 2 | `on:` trigger | Keep `workflow_dispatch:` (D-08 manual fallback) |
| 3 | job level | Add `permissions: id-token: write` + `contents: read` (D-10) |
| 4 | `actions/checkout` step | `@v3` → `@11bd71901bbe5b1630ceea73d27597364c9af683 # v4.2.2` (D-09) |

| 6 | After install step | Insert `npm run lint` step and `npm test` step before publish (D-08 gate) |
| 7 | publish run command | `npm publish --access public` → `npm publish --provenance --access public` (D-10) |

**Target structure** (from RESEARCH.md Pattern 5 — complete replacement):
```yaml
name: Publish

on:
  release:
    types: [published]
  workflow_dispatch:

jobs:
  publish:
    runs-on: ubuntu-latest
    permissions:
      id-token: write
      contents: read

    steps:
      - name: Checkout
        uses: actions/checkout@11bd71901bbe5b1630ceea73d27597364c9af683 # v4.2.2

      - name: Setup Node
        uses: actions/setup-node@49933ea5288caeca8642d1e84afbd3f7d6820020 # v4.4.0
        with:
          node-version: 20
          registry-url: https://registry.npmjs.org
          cache: 'npm'

      - name: Install
        run: npm ci

      - name: Lint
        run: npm run lint

      - name: Test
        run: npm test

      - name: Publish
        run: npm publish --provenance --access public
        env:
          NODE_AUTH_TOKEN: ${{ secrets.NPM_ACCESS_TOKEN }}
```
