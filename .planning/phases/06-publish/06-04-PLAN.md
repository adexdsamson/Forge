| Boundary | Description |

| publish.yml → npmjs.org | npm publish uses NODE_AUTH_TOKEN from NPM_ACCESS_TOKEN GitHub Secret; transmitted over HTTPS; never echoed in logs |
| npm registry → smoke project | npm install fetches @adexdsamson/forge@1.0.0 tarball from registry.npmjs.org over HTTPS; integrity verified by npm lockfile SHA |

| T-06-04-02 | Tampering | Action hijack via unpinned GitHub Actions | accept | publish.yml already has SHA-pinned actions (confirmed from workflow: checkout@11bd71901bbe5b1630ceea73d27597364c9af683, setup-node@49933ea5288caeca8642d1e84afbd3f7d6820020); no new actions are added in this plan |
