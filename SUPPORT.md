# Getting help with Forge

Forge uses **GitHub Discussions** as the central place for community help and conversation, and **Issues** for confirmed bugs and concrete feature requests.

## Where should this go?

| You want to… | Go to |
|---|---|
| Ask a usage question or "how do I…" | [Discussions → Q&A](https://github.com/adexdsamson/Forge/discussions/categories/q-a) |
| Suggest an API change or feature idea | [Discussions → Ideas](https://github.com/adexdsamson/Forge/discussions/categories/ideas) |
| Share something you built | [Discussions → Show & Tell](https://github.com/adexdsamson/Forge/discussions/categories/show-and-tell) |
| Report a reproducible bug | [Open an issue](https://github.com/adexdsamson/Forge/issues/new?template=bug_report.yml) |
| Propose a concrete feature with a clear API | [Open an issue](https://github.com/adexdsamson/Forge/issues/new?template=feature_request.yml) |

## Before you post

- Search [open and closed Discussions](https://github.com/adexdsamson/Forge/discussions?discussions_q=) and [Issues](https://github.com/adexdsamson/Forge/issues?q=is%3Aissue) — your question may already be answered.
- Skim the [README](./ReadMe.md) and [API reference](./docs/API.md).
- Include a minimal reproduction (CodeSandbox/StackBlitz or a small snippet) — it's the single biggest factor in getting a fast, useful answer.

## Security

Please do **not** open public issues or discussions for security vulnerabilities. See the project's security policy or contact the maintainer privately.
